# Quote Assistant Frontend

This is the frontend for the Quote Assistant application. It's built with React, Vite, TypeScript, and Tailwind CSS.

## Getting Started

1. Install dependencies
```
npm install
```

2. Start the development server
```
npm run dev
```

3. Build for production
```
npm run build
```

## Features

- Simple form interface for entering shipment details
- Real-time quote calculation
- Price breakdown and delivery estimate
- Responsive design with Tailwind CSS

## API Integration

The frontend connects to a FastAPI backend running on `http://localhost:8000`. Make sure the backend is running before submitting quotes.
